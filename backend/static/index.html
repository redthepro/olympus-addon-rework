API availability and privacy

Forever API collection is disabled pending official Blizzard documentation. The live addon census remains available. This community project is not endorsed by Blizzard.

Roster data stays on this computer and is deleted after 29 days without a successful refresh, or when a target is removed. Cleanup runs while this companion is open and before cached data is read on restart. Do not archive exports or database backups beyond 30 days. Never share developer credentials.
